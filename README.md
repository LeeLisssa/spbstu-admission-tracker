# Сервис мониторинга конкурсных списков СПбПУ

Telegram-бот для отслеживания изменений в конкурсных списках и документах приёмной комиссии СПбПУ.

## Участники
- Хисматова Елизавета Алексеевна, группа 5130904/40101 (индивидуальный проект)

## Тема
Сервис мониторинга изменений в конкурсных списках и документах приёмной комиссии СПбПУ.

## Технологический стек
- Python 3.11+, aiogram 3
- PostgreSQL
- Docker Compose
- Парсинг страниц сайта приёмной комиссии СПбПУ

## Статус
Этап согласования темы с преподавателем.
